Share this PC's screen

Streams this computer's desktop to an RTSP URL you paste into the VRChat video player. Give it a tc-chat room id to also publish the capture there, so any consensus-elected relay — or a direct viewer — can pick it up without a browser client.

Captures the primary monitor (monitor selection may come later); audio is not shared yet, and publishing into a room requires native capture (Windows).

Relay a tc-chat share

Relays a screen already being shared in a tc-chat room, so VRChat viewers can watch it.

Type a room id above, or set a default relay room in Settings.

Multiple viewers? Each runs mistl stream relay in the same room — a leader is elected automatically and the sharer only uploads once.
